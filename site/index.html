TigranaTheme workshop

A five-minute first project

Your first custom theme

Give your notebook softer panels, an accent under each heading, and a tidy word-count badge. You only need a few lines of Advanced CSS.

1. Make your own copy

Open Settings → Appearance, choose Default, then select Create theme. Name it Quiet Corners. This creates a draft; the built-in Default stays available.

In Visual, pick an accent you like for both light and dark mode. For this first project, leave Plasma glass off under Advanced surfaces.

2. Add a little CSS

Open Advanced CSS. Replace the contents of Custom CSS with this example. The generated CSS is read-only; leave it alone.

:scope {
  --tigrana-workspace-inset: 12px;
  --tigrana-panel-gap: 12px;
  --tigrana-panel-radius: 14px;
}

.ProseMirror h2 {
  padding-bottom: 0.3em;
  border-bottom: 2px solid var(--tigrana-accent);
}

.note-status-bar {
  border: 1px solid var(--tigrana-border);
  border-radius: 6px;
  background: var(--tigrana-surface);
  color: var(--tigrana-text);
  box-shadow: none;
}

:scope means the notebook area. The first rule gives panels breathing room and rounder corners. .ProseMirror h2 targets second-level headings in your notes. .note-status-bar targets the word count.

The var(...) values use your theme’s colors, so the same CSS works in light and dark mode. Try changing 14px to 4px to see squarer panels.

3. Check both appearances

Use the preview to compare light and dark mode. Check selected notes, headings, links, and the word count. Try the navigation options and toggle the outline. Open Theme check and review its findings.

If you see a CSS error, check braces, semicolons, and spelling. Start with this example again if needed. Tigrana supports a limited set of CSS; remote imports and !important are not supported.

4. Save and try it

Choose Save and use, inspect the light and dark previews, then choose Confirm and save. Open a real note with a Heading 2 to see your underline.

To change your CSS later, open Edit theme. To go back, choose Default in Appearance. Restore default appearance also resets layout and effects.

Ready to share?

Choose Export theme to create a .tigrana-theme file. Someone else can use Import theme to try it. This example uses the app’s existing fonts and needs no downloaded assets.
